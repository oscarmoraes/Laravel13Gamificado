# 🚀 Funil Gamificado Laravel 13 — Dashboard de Livros | SENAI Dev

Aplicação interativa de aprendizado gamificado desenvolvida para a formação **SENAI Dev**, baseada na playlist completa de **Laravel 13** (*Book Library / Dashboard de Livros*).

🔗 **Acesse online via GitHub Pages:**  
👉 **[https://oscarmoraes.github.io/Laravel13Gamificado/](https://oscarmoraes.github.io/Laravel13Gamificado/)**

---

## 🎯 Características e Gamificação

- 🔒 **Bloqueio Real de Aulas**: Cada aula do YouTube só é liberada após responder e acertar o desafio técnico da aula anterior.
- ⚡ **Sistema de XP e Patentes**:
  - 🌱 *Dev Laravel Iniciante* (0 XP)
  - ⚡ *Praticante de Rotas & Blade* (500 XP)
  - 🛠️ *Construtor MVC & Migrations* (1.000 XP)
  - 🚀 *Especialista em Eloquent & Relacionamentos* (1.600 XP)
  - 👑 *Mestre Laravel 13 SENAI* (2.100 XP)
- 🏆 **18 Conquistas Desbloqueáveis**: Uma medalha exclusiva para cada etapa concluída.
- 🔊 **Efeitos Sonoros Web Audio API**: Áudio sintético integrado para acertos, erros e celebração.
- 🎓 **Certificado de Conclusão Dinâmico**: Gerado em tempo real ao concluir todas as 18 aulas, pronto para impressão ou download.
- 📱 **Mobile-First & Responsivo**: Otimizado para telas desde 320px de largura até monitores ultra-wide.

1. **Introdução e Instalação do Laravel 13**
2. **Rotas Básicas e Retorno de Views**

7. **Estilização e Integração de CSS com Vite**
8. **Migrações de Banco de Dados (Migrations)**
9. **Modelos Eloquent e Mapeamento ORM - Parte 1**
10. **Modelos Eloquent e Consultas - Parte 2**
11. **Arquitetura MVC e Controllers**
12. **Paginação de Resultados de Livros**
13. **Relacionamento 1:N (Um para Muitos)**
14. **Criação de Formulários e Métodos HTTP**
15. **Validação de Dados de Formulário e Persistência**
16. **Upload de Arquivos e Capas de Livros**
17. **Formulário de Edição e Atualização (Update)**
18. **Exclusão de Registros e Toques Finais**

## 🛠️ Tecnologias Utilizadas

- **Vue.js 3** (Composition API via CDN)
- **Tailwind CSS** (Design responsivo e Dark Mode)
- **Canvas Confetti** (Efeitos de celebração)
- **Web Audio API** (Sintetizador de áudio)
- **LocalStorage API** (Persistência offline do progresso)
